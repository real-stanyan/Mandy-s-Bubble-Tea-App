# Mandy's Bubble Tea — Android 安装指南 / Install Guide

## 中文版

### 1. 扫码下载
扫码上面的二维码 → 打开 Chrome → 浏览器开始下载 APK 文件 (约 160 MB)

### 2. 允许"安装来自未知来源的应用"
- 当 Android 弹出"出于安全考虑，您的手机不允许安装来自此来源的未知应用"对话框时
- 点 **"设置"** 按钮 → 把"允许此来源"开关打开
- 按返回键返回 → 点 **"安装"** → 完成

### 3. 启动 App
- 在桌面上找到 **Mandy's** 图标 → 点开
- 用 **Google 账号**登录（其它登录方式暂不支持 Android 版）
- 享用 ☕️

### 4. 后续更新
- Phase A 期间：新版本通过新的二维码替换，需重新扫码下载
- 上架 Google Play Store 后：自动更新，无需手动操作
- 你的账号 / 积分 / 订单历史在更新后全部保留

### 5. 反馈渠道
- App 内 → 订单详情 → "举报问题"（带照片）
- 或直接联系 hello@mandybubbletea.com

## English Version

### 1. Scan the QR Code
Scan the QR code above → opens Chrome → downloads the APK file (~160 MB).

### 2. Allow "Install from unknown sources"
- When Android shows "For your security, your phone is not allowed to install unknown apps from this source"
- Tap **Settings** → toggle **Allow from this source** ON
- Press Back → tap **Install** → Done

### 3. Launch the App
- Find the **Mandy's** icon on your home screen → tap it
- Sign in with your **Google account** (other sign-in methods are iOS-only for now)
- Enjoy ☕️

### 4. Future Updates
- During Phase A: new versions distributed via new QR codes (re-scan to update)
- After Google Play Store release: auto-update, no action required
- Your account / stars / order history are preserved across updates

### 5. Feedback
- Inside app → order detail page → "Report a problem" (with photos)
- Or email hello@mandybubbletea.com directly
